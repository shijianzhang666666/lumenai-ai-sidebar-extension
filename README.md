## 简介 | Introduction
**中文**
Lumen AI 是一款轻量浏览器AI侧边栏扩展，一款好用的网页AI助手。无需切换标签页，在任意网页侧边随时调用大模型。支持网页总结、划词翻译、文本润色、代码解释、问答与内容创作，兼容OpenAI格式中转API，自定义性强，开箱即用，帮助你提升浏览、学习与办公效率。

**English**
Lumen AI is a lightweight browser AI sidebar extension and webpage AI assistant. Call large language models from the sidebar on any webpage without switching tabs. It supports webpage summarization, highlight translation, text polishing, code explanation, Q&A and content creation. Compatible with OpenAI-compatible relay APIs, highly customizable and ready to use out of the box to boost your browsing, study and productivity.

- ✍️ **选中文本处理 | Text Selection AI Tools**：AI聊天、AI工作台、代码解释、整页翻译、划词翻译 / AI Chat, AI Workbench, code explanation, full-page translation, highlight word translation
- ⚙️ **自定义API接口 | Custom OpenAI API Endpoint**：兼容OpenAI中转格式，自由切换多模型 / Supports OpenAI compatible relay format and switching between multiple LLMs
