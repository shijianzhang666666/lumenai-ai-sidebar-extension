## 简介 | Introduction
**中文**
Lumen AI 是一款轻量浏览器侧边栏AI扩展，无需切换标签页，在任意网页侧边随时调用大模型。支持文本总结、翻译、润色、代码解释、问答创作，适配主流AI中转接口，自定义性强，开箱即用，高效提升浏览与办公效率。

**English**
Lumen AI is a lightweight AI sidebar extension for browsers. You can call large language models anytime from the sidebar on any webpage without switching tabs. It supports text summarization, translation, polishing, code explanation, Q&A and content creation. Compatible with mainstream AI relay APIs, highly customizable and ready to use out of the box to boost your browsing and productivity.

---

## 功能特点 | Features
- 📌 **常驻侧边栏 | Persistent Sidebar**：任意网页一键唤起，不打断当前浏览 / One-click activation on any webpage without interrupting your browsing
- ✍️ **选中文本处理 | Text Selection Actions**：AI聊天、AI工作台、解释代码、整页翻译、划词翻译 / AI Chat, AI Workbench, code explanation, full-page translation, word highlighting translation
- ⚙️ **自定义接口 | Custom API Endpoint**：兼容OpenAI格式中转，支持多模型切换 / Supports OpenAI-compatible relay format and switching between multiple models
- 🎨 **轻量化设计 | Lightweight Design**：低资源占用，界面简洁清爽，无广告无需注册，可接入自有KEY，附带免费KEY申请向导 / Low resource usage, clean UI, no ads and no registration required. Supports your own API keys, with a guide for free key application
- 🔖 **会话记忆 | Conversation Memory**：保留对话上下文，支持新建/清空会话 / Keep chat context, support creating new chats and clearing history
